# Email Signature Generator

A simple web tool to create professional email signatures directly in the browser.

## Features

- Create a custom email signature
- Add personal and company details
- Add social profile links
- Add an image or logo
- Preview the signature
- Copy the generated signature
- Runs directly in the browser
- No account required
- No server-side storage

## Privacy

This tool runs locally in the user's browser.

The data entered by the user is not intentionally sent to external services, stored on a server, or logged by this project.
